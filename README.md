A powerful WordPress plugin to create custom post sliders based on selected categories with full control over design and behavior.

== Description ==

Ahmed Slider is a fully responsive WordPress plugin that allows you to display your posts in a customizable slider format. Choose the category, number of posts, speed, autoplay, and more. Each slider has its own unique shortcode for use anywhere on your site.

**Features:**

- Create unlimited sliders
- Select specific categories
- Define number of posts per slider
- Autoplay and transition speed settings
- Toggle post thumbnails and titles
- Shortcode generator
- Live preview of the slider in admin
- Modern, responsive layout

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/ahmed-slider` directory, or install the plugin directly through the WordPress plugins screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Go to the **Ahmed Slider** menu in the WordPress admin to start creating your sliders.

== Frequently Asked Questions ==

= Can I display multiple sliders? =  
Yes! Each slider has a unique shortcode like `[ahmed_slider id="1"]`.

= Is it responsive? =  
Absolutely. It adapts to all screen sizes.

= Can I change the design of the slider? =  
You can fully customize the slider via the plugin settings and by editing the CSS file in the `assets/` folder.
