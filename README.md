إضافة ووردبريس متقدمة لعرض المقالات من تصنيفات مخصصة داخل سلايدر أنيق وسهل الاستخدام.

== Description ==

Ahmed Slider هي إضافة احترافية تتيح لك عرض مقالاتك على شكل سلايدر عصري داخل موقعك. الإضافة توفر خيارات تحكم كاملة بالسلايدر، مثل: اختيار التصنيف، عدد المقالات، إظهار الصور، العناوين، سرعة الحركة، وتفعيل التشغيل التلقائي. تدعم التحديث من GitHub، وتأتي بواجهة إدارة أنيقة داخل لوحة تحكم ووردبريس.

== Features ==

* اختيار تصنيف المقالات المراد عرضها.
* تحديد عدد المقالات داخل السلايدر.
* التحكم بسرعة التبديل والتشغيل التلقائي.
* إظهار أو إخفاء الصور والعناوين.
* دعم التحديث من GitHub.
* حذف وتعديل السلايدرات بسهولة.
* واجهة إدارة أنيقة وسهلة الاستخدام.
* استخدام SweetAlert للتنبيهات التفاعلية.

== Installation ==

1. قم برفع ملفات الإضافة إلى مجلد `/wp-content/plugins/ahmed-slider`
2. فعّل الإضافة من خلال لوحة "الإضافات"
3. توجه إلى "Ahmed Slider" من القائمة الجانبية لإنشاء سلايدر جديد
4. انسخ الشورت كود وأضفه إلى أي صفحة أو مقالة:
   `[ahmed_slider id="1"]`
